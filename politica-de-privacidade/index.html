Política de privacidade

Esta página descreve, de forma direta, quais dados este site coleta, para que servem e para onde vão — com base no que está efetivamente implementado no site hoje.

Esta é uma minuta técnica baseada nos fluxos de dados identificados no código do site. Ela ainda não substitui uma revisão jurídica e precisa da confirmação de dados institucionais (razão social, CNPJ, endereço, contato do responsável pelo tratamento) antes de valer como documento final. Ver lista de pendências ao final.

1. O que este site coleta

Três fluxos distintos de dados acontecem neste site, e vale a pena separá-los porque têm destinos diferentes:

1.1 Navegação (analytics próprio)

Ao visitar o site, um script de medição registra eventos como visualização de página e cliques em botões (por exemplo, no WhatsApp). Esse script usa um identificador de navegador rotativo — não é um dado que, sozinho, identifica uma pessoa. Nome, e-mail, telefone ou conteúdo de formulário não são enviados a esse sistema de analytics. Você pode impedir essa coleta usando bloqueadores de rastreamento no navegador; o envio de formulários de contato continua funcionando normalmente mesmo assim.

1.2 Formulário de contato

Quando você preenche um formulário de contato (nome, e-mail, WhatsApp e, conforme o formulário, nome do escritório e serviço de interesse), esses dados são enviados a dois destinos: uma planilha e notificação por e-mail da equipe Mega ADS (via Google Apps Script/Google Sheets), e o painel interno de atendimento de leads da Mega ADS. Esses dados são usados exclusivamente para que um especialista entre em contato com você sobre os serviços da Mega ADS.

1.3 WhatsApp

Os links e botões de WhatsApp abrem uma conversa direta pelo aplicativo ou site do WhatsApp. Essa conversa é regida pela política de privacidade do WhatsApp/Meta, fora do controle deste site.

2. Com quem os dados são compartilhados

Os dados de formulário são compartilhados com os seguintes fornecedores, estritamente para operar o que está descrito acima:

  • Google (Apps Script / Google Sheets / Gmail): recebe os dados do formulário para registro em planilha e notificação por e-mail à equipe.
  • Painel interno da Mega ADS: sistema próprio onde a equipe comercial acompanha leads recebidos pelo site.

Os dados não são vendidos nem compartilhados com terceiros para fins de publicidade.

3. Cookies e armazenamento local

O site usa armazenamento local do navegador (não necessariamente cookies tradicionais) para manter o identificador de visitante do analytics mencionado em 1.1. Não há, até a publicação desta página, pixels de redes sociais de terceiros instalados além do mencionado aqui.

4. Seus direitos

Você pode solicitar a confirmação, correção ou exclusão dos dados que enviou por formulário entrando em contato pelo canal informado na página de Contato. O prazo de resposta e o canal formal de atendimento a esse tipo de solicitação estão sujeitos a confirmação — ver pendências abaixo.

5. Informações ainda pendentes de confirmação

  • Razão social, CNPJ e endereço do responsável pelo tratamento dos dados (controlador).
  • Canal e prazo formal para atendimento a solicitações de titulares de dados (acesso, correção, exclusão).
  • Período de retenção dos dados de formulário na planilha/Apps Script e no painel.
  • Confirmação se há, ou haverá, uso de cookies de terceiros para publicidade (remarketing) — não identificado no código nesta data.

Última verificação do conteúdo técnico desta página: data da geração deste site. Revisar sempre que um novo fornecedor de dados for integrado.
