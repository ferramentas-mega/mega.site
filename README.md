# Site Mega ADS — landing page

Site estático (HTML + JS próprios). Não depende de WordPress, Elementor nem plugins.

## Estrutura
- index.html — a página
- support.js — runtime dos componentes
- assets/ — imagens (webp) e vídeos (webm/mp4)
- .htaccess — cache + compressão + MIME (Apache/HostGator)

## Publicar
Subir os 4 itens acima para a pasta desejada no servidor, mantendo a estrutura.
O assets/ precisa ficar ao lado do index.html.
